# Scope

## In

- Create, edit, delete, and set the priority of a task.
- Move a task across status Todo, In Progress, and Done.
- Filter the board by status and show a task count.
- Form validation, plus loading, empty, and error states.
- English and Arabic catalogues with the same keys.
- A health route that returns 200.
- Unit tests, Tailwind styling, shadcn/ui, and a Vercel deploy.

## Out

- Sign-in and accounts.
- Saving a task to a hosted database.
- File uploads, payments, email, background jobs, search, and an in-product assistant.
- Browser end-to-end tests.
- Anything the brief does not name.

T01 implements the tasks path inside the architecture that already exists. Later tasks do not re-scaffold the stack.
