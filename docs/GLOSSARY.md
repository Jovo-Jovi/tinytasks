# Glossary

- **task**: One unit of work a developer tracks on the TinyTasks board.
- **status**: Where a task sits. The only statuses are Todo, In Progress, and Done.
- **priority**: How soon a task should be done relative to the others.
- **filter**: A control that shows tasks of one status.
- **task count**: How many tasks are in a status, or on the whole board.
